# Project Astra

Personal portfolio — "Where Intelligence Meets Innovation."

Built with React, Vite, and React Router. Includes PWA support with offline caching.

## Tech Stack

- React 18
- Vite 5
- React Router 6
- CSS (no framework)

## Local Development
npm install
npm run dev


Open http://localhost:3000

## Build
npm run build
npm run preview 


## Deploy

Designed for Render. The service worker and manifest make it installable as a PWA.
